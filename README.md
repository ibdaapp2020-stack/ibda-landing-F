# IBDA Smart Business – דף נחיתה

דף נחיתה סטטי למערכת IBDA Smart Business: מסכי מערכת אמיתיים (ללא שמות ופרטים מזהים), סריקת מסמכים ב-AI, התאמה לעסק, ושתי דרכי כניסה – תשלום וקבלת המערכת, או השארת פרטים.

כתובת חיה: https://ibdaapp2020-stack.github.io/ibda-landing-F/

## מבנה

- `index.html` – הדף כולו (תוכן, עיצוב וסקריפט בקובץ אחד). זה קובץ המקור לעריכה.
- `assets/screens/` – 13 מסכי מערכת בפורמט WebP
- `assets/og.jpg` – תמונת שיתוף (1200×630) לוואטסאפ ולרשתות
- `favicon.svg`, `apple-touch-icon.png` – אייקונים
- `.nojekyll` – GitHub Pages מגיש את הקבצים כמו שהם, בלי עיבוד Jekyll

## איך זה עובד

- **כל כפתורי "לתשלום וקבלת המערכת"** (כולל הפס התחתון בטלפון) פותחים קודם חלון קצר: שם מלא, טלפון ואימייל. אחרי "המשך לתשלום" הפרטים נשלחים למייל העסק (`ibda.app2020@gmail.com`) והלקוח עובר לעמוד התשלום ב-Grow באותו חלון.
- הדף עצמו לא אוסף ולא שומר פרטי כרטיס אשראי. הכרטיס מוזן רק בעמוד התשלום המאובטח של Grow.
- **הפעלה חד-פעמית של קבלת הפרטים:** הפנייה הראשונה לשירות FormSubmit שולחת מייל הפעלה לכתובת העסק. יש ללחוץ שם על Activate. עד אז הפרטים לא יגיעו, והלקוחות ממשיכים לתשלום כרגיל.
- אם שליחת הפרטים נכשלת או מתעכבת (יותר מכ-3 שניות), הלקוח ממשיך לתשלום בכל זאת. אף לקוח לא נתקע.
- **המגבלה:** דף סטטי לא יכול לאלץ מילוי. לחיצה עם Ctrl/Cmd, פתיחה בלשונית חדשה, או דפדפן בלי JavaScript מעבירים ישר לתשלום בלי השארת פרטים.
- כדי לשנות את יעד הפרטים מחפשים `formsubmit.co/ajax` ב-`index.html` (קבוע `LEAD`). כדי לחבר גיליון Google או CRM מחליפים את הכתובת והשדות באותו מקום.
- **"השארת פרטים"** (טופס נפרד בתחתית הדף) לא שולח לשרת. אחרי בדיקת שם וטלפון נפתח וואטסאפ עם הודעה מוכנה למספר העסק, והלקוח לוחץ שליחה. כדי לשנות את המספר מחפשים `972528871655` ב-`index.html`.
- **בטלפון** (עד 900px) כל מסך מערכת הוא שורה שנפתחת בלחיצה (אחת פתוחה בכל רגע), עם פס תחתון קבוע: תפריט, תשלום, וואטסאפ. בדסקטופ ובדפדפן בלי JavaScript מוצג הדף המלא.
- אין עוגיות ואין אנליטיקס. הגופן (Rubik) נטען מ-Google Fonts.

## עדכון והפעלה

כל השינויים נעשים ב-`index.html` ובתיקיית `assets/`. אחרי דחיפה ל-`main` האתר מתעדכן תוך דקה-שתיים.

הפעלת GitHub Pages: Settings ← Pages ← Source: Deploy from a branch ← Branch: `main`, תיקייה `/ (root)`.
