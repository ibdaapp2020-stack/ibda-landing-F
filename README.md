# IBDA Smart Business – דף נחיתה

דף נחיתה סטטי למערכת IBDA Smart Business: מסכי מערכת אמיתיים (ללא שמות ופרטים מזהים), סריקת מסמכים ב-AI, התאמה לעסק, ושתי דרכי כניסה – תשלום וקבלת המערכת, או השארת פרטים.

כתובת חיה: https://ibdaapp2020-stack.github.io/ibda-landing-F/

## מבנה

- `index.html` – הדף כולו (תוכן, עיצוב וטופס בקובץ אחד)
- `assets/screens/` – 13 מסכי מערכת בפורמט WebP
- `assets/og.jpg` – תמונת שיתוף (1200×630) לוואטסאפ ולרשתות
- `favicon.svg`, `apple-touch-icon.png` – אייקונים
- `.nojekyll` – GitHub Pages מגיש את הקבצים כמו שהם, בלי עיבוד Jekyll

## איך זה עובד

- **"לתשלום וקבלת המערכת"** מעביר לעמוד התשלום ב-Grow. הדף עצמו לא אוסף ולא שומר פרטי כרטיס אשראי.
- **"השארת פרטים"** לא שולח לשרת. אחרי בדיקת שם וטלפון נפתח וואטסאפ עם הודעה מוכנה למספר העסק, והלקוח לוחץ שליחה. כדי לשנות את המספר מחפשים `972528871655` ב-`index.html`.
- אין עוגיות ואין אנליטיקס. הגופן (Rubik) נטען מ-Google Fonts.
- אם רוצים לשמור פניות במקום פתיחת וואטסאפ, אפשר לחבר את הטופס לשירות כמו Formspree, Web3Forms או Google Apps Script.

## עדכון והפעלה

כל השינויים נעשים ב-`index.html` ובתיקיית `assets/`. אחרי דחיפה ל-`main` האתר מתעדכן תוך דקה-שתיים.

הפעלת GitHub Pages: Settings ← Pages ← Source: Deploy from a branch ← Branch: `main`, תיקייה `/ (root)`.
